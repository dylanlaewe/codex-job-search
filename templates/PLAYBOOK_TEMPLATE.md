# End-to-End Job Search Playbook

Version: 1.0.0  
Last updated: YYYY-MM-DD

## Purpose

Describe what this job-search system is intended to accomplish, its evidence standards, and where human input remains required.

## Initial setup

Document the private directory layout, required uploads, profile interview, resume inventory, search strategy, tracker schema, and browser/account setup.

## Application cycle

Document the exact sequence from role verification through fit scoring, document selection, form completion, final audit, submission verification, tracker write, and tab closure.

## Quality controls

Record the rules for grounded claims, employer concentration, duplicate detection, filename safety, form auditing, confirmations, and one-writer tracker concurrency.

## Failure recovery

Document how to recover from login gates, OTPs, CAPTCHAs, expired sessions, upload failures, lost tabs, parser errors, and uncertain submission status.

## Continuous improvement

For each material workflow change, update this playbook and `IMPROVEMENT_LOG.md`, increment the version, and record how the change was validated.
