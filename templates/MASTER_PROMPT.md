# Master Prompt

> Use the installed job-search operator skill. Load my private job-search system at `<JOB_SEARCH_ROOT>`. Audit the candidate evidence, stable answer bank, preferences, resume inventory, search strategy, and tracker before acting. For this session, complete `<COUNT>` qualified applications. Prioritize `<PRIMARY_ROLES>` while maintaining this mix: `<ROLE_MIX>`. Use official employer postings and reject unrealistic roles. Before opening each application, run a full-tracker duplicate gate using normalized company and title, requisition ID, and canonical URL; default to one application per employer per 30 days unless I explicitly approve a named exception. For each role, select or create an evidence-backed ATS resume, create a cover letter when required or strategically useful, complete every required form question, audit the final form, obtain any required action-time confirmation, verify submission, update the tracker, close the tab, and repeat. Use delegated preparation when authorized, but keep browser submission to one application at a time. After the tracker verifies `<COUNT>` Applied rows for the current date, research one relevant person per company, draft a short evidence-backed outreach email, log the contact and draft in the private Outreach table, obtain the required action-time confirmation, send, and record the result. Keep LinkedIn activity manual and follow up once after five business days if there is no response. Record any material process improvement in the playbook and improvement log.

## Single-role version

> Use the installed job-search operator for `<JOB_URL>`. Verify the role is open and realistic, score the fit, select or create the correct resume, draft a cover letter if it adds value, complete and audit the application, request only the handoffs the site genuinely requires, verify submission, and update the tracker.

## Outreach-only version

> Use the installed job-search operator. Read the private application and outreach tables, then build an outreach queue from the exact Applied rows for `<DATE_OR_BATCH>`. Research one relevant person per company, prefer verified work addresses, and keep LinkedIn activity manual. Draft concise messages that name the role, explain why the person is relevant, connect one verified experience point, and make a small informational ask. Log every contact and draft before sending, obtain the required action-time confirmation immediately before the batch is sent, record each visible send, and schedule one follow-up after five business days.
