## Selection rules

- Reuse when the current version already covers the role's main responsibilities and most mandatory tools.
- Light-tailor supported terminology, bullet order, and skills order when the story is already correct.
- Create a reusable family variant when several desirable roles need a materially different narrative.
- Create a one-off version only for an unusually high-priority role.
- Never claim unsupported tools, titles, ownership, metrics, or domain experience.
- Never upload a file whose name identifies another employer.
