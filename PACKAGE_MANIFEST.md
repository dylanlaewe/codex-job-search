# Package Manifest

- Package: Human-in-the-Loop Job Search Starter Kit
- Version: 1.1.0
- Date: 2026-11-09

## Included

- Public setup guide.
- Generic workflow diagram.
- LinkedIn post draft.
- Blank candidate-profile, answer-bank, user-preferences, search-strategy, resume-index, cover-letter-voice, application-tracker schema, outreach schema, playbook, and improvement-log templates.
- Canonical private-root layout and privacy-safe copying instructions.
- Generic Codex skill entrypoint.
- A privacy-safe post-application outreach guide with contact selection, message standards, LinkedIn boundaries, follow-up rules, and measurement.

## Excluded by design

- Personal contact and demographic information.
- Resumes and cover letters.
- Application tracker data.
- Contact names, profile URLs, email addresses, message history, and outreach outcomes.
- Employer application artifacts.
- Passwords, OTPs, cookies, and browser sessions.
